## 仓库结构

```text
atguigu-note/
├── langchain/     # LangChain 课件 + 代码 + 分 P 目录
└── langgraph/     # LangGraph 课件 + 代码 + 分 P 目录
```

每个子目录下均包含：

- `课件/`：Markdown 课件，可直接在线预览
- `代码/`：Jupyter Notebook 实战代码
- `README.md`：完整视频分 P 目录（点击即可跳转对应集数）

## 学习建议

1. 打开对应课程的 README，按分 P 在 B 站在线观看
2. 对照 `课件/` 复习笔记
3. 打开 `代码/` 中的 Notebook 动手跟练
